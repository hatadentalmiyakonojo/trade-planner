株式トレードプランナー セットアップ手順書

このアプリは GitHub Pages（無料のホームページ置き場）に置くと、

毎朝6時半に株価データが自動更新される仕組みになっています。

在庫発注アプリや打刻アプリと同じ方式なので、作業の流れはほぼ同じです。

所要時間はおよそ20〜30分。一度設定すれば、あとは何もしなくて大丈夫です。

💡 GitHub Pagesに置かず、index.html をダブルクリックして開くだけでも使えます（オフラインモード）。
その場合は自動データ更新がないため、銘柄データは「CSV/コピペ取り込み」で入れます。

全体の仕組み

```

GitHub（毎朝6:30に自動実行）

└─ yfinance で株価取得 → data/ フォルダを更新

↓

GitHub Pages（アプリの置き場所・固定URL）

↓

iPad / Mac のブラウザでアプリを開く → 最新データを自動読込

```

  • 株価は前日終値ベースです（リアルタイムではありません）。夜〜朝にプランを立てて、翌日発注する使い方を想定しています。
  • プラン・ジャーナル・設定は端末の中（ブラウザのlocalStorage）に保存されます。GitHubには送られません。

手順1: 新しいリポジトリを作る

  1. Safariで https://github.com にアクセスし、いつものアカウントでログイン
  2. 右上の「＋」→「New repository」をクリック
  3. 次のように入力:
    • Repository name: trade-planner
    • Public を選択（Privateだと無料プランでPagesが使えません）
    • ほかはそのまま
  4. 緑の「Create repository」をクリック

手順2: アプリのファイルをアップロードする

  1. 作ったリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）をクリック
  2. Macの Finder で Desktop/Ai/株式トレードプランナー フォルダを開き、次のファイルとフォルダをドラッグ＆ドロップ:
    • index.html
    • README.md
    • scripts フォルダ（中に fetch_data.py と requirements.txt）
    • ※ data フォルダと .venv はアップロード不要（dataは手順4で自動生成されます）
  3. 下の緑ボタン「Commit changes」をクリック

手順3: 自動更新の仕組み（ワークフロー）を登録する

.github で始まる隠しフォルダはドラッグできないので、GitHubの画面上で作ります。

  1. リポジトリ上部の「Actions」タブをクリック
  2. 「set up a workflow yourself」をクリック（見つからない場合は「Skip this and set up a workflow yourself」）
  3. ファイル名が main.yml になっているので daily.yml に変更
  4. 大きな入力欄に、Macの Desktop/Ai/株式トレードプランナー/.github/workflows/daily.yml の中身を全部コピーして貼り付け
    • Finderで見えない場合: このフォルダの daily.yml の中身.txt にも同じ内容を入れてあります
  5. 右上の「Commit changes...」→ もう一度「Commit changes」

手順4: 初回のデータ取得を実行する

  1. 「Actions」タブ →左側の「相場データ自動更新」をクリック
  2. 右側の「Run workflow」→ 緑の「Run workflow」をクリック
  3. 3〜5分待つと ✅ 緑のチェックがつき、リポジトリに data フォルダができています
    • ❌ 赤になったら、もう一度「Run workflow」（Yahoo側の一時的な混雑で失敗することがあります）

これ以降、平日の朝6:30ごろに自動で同じ処理が走ります。何もしなくてOKです。

⚠️ GitHubの仕様で、リポジトリに60日間まったく更新がないと自動実行が止まりますが、
このワークフロー自体が毎日データを更新するので、実質止まりません。
もし長期間止めていた場合は「Run workflow」を1回手で押せば再開します。

手順5: ホームページとして公開する（Pages）

  1. リポジトリの「Settings」→ 左メニューの「Pages」
  2. 「Source」を Deploy from a branch、Branchを main / (root) にして「Save」
  3. 1〜2分後、上部に URL が表示されます:

https://（アカウント名）.github.io/trade-planner/

  1. この URL を iPad の Safari で開き、共有ボタン →「ホーム画面に追加」
⚠️ URLは変えないでください。 プランやジャーナルはこのURL単位で端末に保存されるため、
リポジトリ名の変更＝URLの変更をすると、保存済みデータが見えなくなります。
（ホーム画面のアイコンを削除→再追加するのは問題ありません）

使い方（毎日の流れ）

  1. セクタータブ: 今どのセクターにお金が入っているかを確認（「資金流入中」バッジ）
  2. セクターカードをタップ → スクリーナー: そのセクター内の候補銘柄が高スコア順に並ぶ
  3. 銘柄をタップ → チャート分析: フィボナッチと押し目ゾーンを確認
  4. 「トレードプラン生成」ボタン → 買い指値3本・逆指値・利確目標・株数が自動計算される
    • 判定が「見送り推奨」（赤）のときは無理をしない。それも大事な判断です
  5. 「注文票をコピー」→ 証券会社アプリで注文 → 「プランを保存」
  6. 約定したらプランタブで約定記録、決済したら決済記録→クローズ確定
  7. ジャーナルタブで勝率・期待値・計画遵守率を振り返る

1日の運用リズム（楽天証券・3回チェック向け）

株価データは前日終値ベース（毎朝6:30更新）なので、「朝にプランを立てて発注し、日中は約定確認だけ」が基本形です。

タイミングやること
朝（〜8:55 寄り前）メインの時間。①セクター→スクリーナーで候補確認 ②チャートでプラン生成 ③楽天証券で発注（買い=指値、損切りは「逆指値付通常注文」で買いと同時に設定）④保有株の逆指値が生きているか確認
昼（〜12:25 後場前）前場の約定を確認→アプリの「プラン」タブに約定記録。急なニュースで前提が崩れた銘柄がないかだけチェック
後場開始60分約定した銘柄の損切り注文の入れ忘れ確認（最重要）。T1到達していれば利確の約定確認。新規の飛び乗りはしない（データが前日ベースのため、新規は翌朝に回すのが原則）

楽天証券の注文との対応: 買いE1〜E3=通常の指値（期間指定）／損切り=逆指値付通常注文（成行）／利確T1・T2=指値売り／残りのトレーリング=トレール注文（値幅はプラン画面に表示される「2.5×ATR」の金額）。

最初にやっておくこと

  • 設定タブで「総資金」と「1トレードのリスク%」を入力（初期値: 300万円・1%）
  • 中長期投資をする銘柄は、チャート画面の「ファンダ評価」で決算チェックを入れるとスコアが正確になります

データについて

  • 対象銘柄: 日経225構成銘柄＋米国S&P100（約320銘柄）＋主要指数・セクターETF
  • それ以外の銘柄は「CSV/コピペ取り込み」で個別に追加できます
    • stooq.com で「7203.jp」のように検索 →「データをダウンロード」→ CSVを取り込み
    • または Yahoo!ファイナンスの時系列表をコピーして貼り付け
  • バックアップ: 設定タブ →「バックアップを保存」を月1回程度（プラン・記録が守られます）

困ったとき

症状対処
「オフライン」と表示されるネット接続を確認 → 設定タブ「データ再読込」
データの日付が古いGitHubのActionsタブで最新の実行が✅か確認。❌なら「Run workflow」
銘柄が検索で出てこないユニバース外の銘柄です。「CSV/コピペ取り込み」で追加
保存に失敗と出る設定タブ「バックアップを保存」→「相場キャッシュ削除」
プランが「見送り推奨」ばかり相場全体が弱い時期です。セクタースコア70以上が増えるまで待つのも戦略

大事な注意（必ずお読みください）

  • 本アプリは計算・分析ツールであり、投資助言や銘柄推奨ではありません。
  • 株価データは前日終値ベースで、遅延・欠損があり得ます。発注前に必ず証券会社の画面で実際の株価・呼値を確認してください。
  • 逆指値・指値の呼値単位は一般銘柄の刻みで計算しています。銘柄によっては単位が異なることがあります（その場合は近い価格に読み替えてください）。
  • 投資の最終判断と結果責任はご自身に帰属します。余裕資金の範囲でご利用ください。
