# 株式トレードプランナー

スイング・中長期の株式投資 意思決定支援アプリ（単一HTML・オフライン動作対応）。

- **セクター資金フロー**: TOPIX-17 / 米SPDRセクターETFの相対強度・出来高から資金の向かい先をスコア化
- **スクリーナー**: 日経225＋S&P100から、強いセクター内のスイング/中長期候補を抽出
- **チャート分析**: ローソク足・SMA・RSI・MACD・ZigZagスイング検出・フィボナッチ自動描画
- **トレードプラン**: 分割エントリー3本の指値・逆指値・分割利確・ポジションサイズ・リスクリワード比を自動計算
- **ジャーナル**: 勝率・期待値・プロフィットファクター・計画遵守率

データは GitHub Actions（`.github/workflows/daily.yml`）が平日朝に yfinance から取得し `data/` に格納。
アプリ（`index.html`）は GitHub Pages で配信すると自動でデータを読み込みます。
オフライン・file:// でもキャッシュとCSV/コピペ取り込みで動作します。

セットアップ手順は `セットアップ手順書.html` を参照。

## 免責事項

本アプリは株式投資の分析・計算を補助するツールであり、投資助言・特定銘柄の売買推奨を行うものではありません。
表示される価格・数量・戦略はすべて過去データに基づく計算例です。相場データには取得遅延・欠損が含まれる場合があります。
投資の最終判断と結果責任は利用者自身に帰属します。
